# VIANA QUERY

Cliente SQL para Protheus / NewDBSql integrado ao VSCode.

## Funcionalidades

* Consulta SQL via WebService Protheus
* Exportação para Excel
* Configuração integrada no painel
* Suporte a Oracle / SQL Server / PostgreSQL

## Requisitos

Necessário compilar o WebService `vianaqueryws.prw` no Protheus.
